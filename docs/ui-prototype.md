# 原型与 Kotlin 界面

`AHD_Camera_Interactive_Prototype.html` 定义共享交互：预览铺满窗口、按比例中心裁切、
右上角全局入口、右侧显示/摄像头/应用设置/关于面板，点击单路画面出现贴边参数卡片，
保留全屏与录像操作。不在预览左上角显示设备路径。行列选择范围为 1–9。

App 保留相同交互与主题/语言设置，帧率和分辨率角标可独立关闭。画面仅在收到实际帧后显示，
错误时遮盖旧帧。选项来自 Camera2，不使用 HTML 中的演示设备或模式数据。
HTML 模拟录像；App 实际写入 MediaStore。HTML 没有固件并发限制；App 禁用系统未公布的
并发组合，启动前检查所选分辨率和录像输出是否可组合。实际帧率独立测量，不伪造固定值。

原生控件保留触摸目标与系统下拉菜单，面板使用透明色而非对实时视频进行昂贵的模糊处理。
修改布局和交互时，应同步修改原型和 Compose；演示图片无需跟随物理摄像头内容更新。


## 鱼眼矫正实验分支

`kotlin-camera2-dewarp` 的每路画面设置增加“近似鱼眼矫正”开关及强度、镜头水平视角、输出水平视野。
开关和参数按摄像头保存，录制期间锁定。弹层高度受限时滚动，展开单路可获得更大调节空间。
HTML 同步提供这些控件并保存参数，但原型使用静态图片，不执行 GPU 重映射；显式显示此区别。
原生 App 的预览和录像共用映射，关闭开关显示原图，帧率角标统计完成的 GPU 输出帧。
